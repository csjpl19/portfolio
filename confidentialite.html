Ce portfolio est présenté par Carl Stephen Junior Pierre Louis. Le formulaire permet de me transmettre une demande de projet, une opportunité professionnelle ou un autre message.

Ce que vous transmettez

Le formulaire recueille votre nom, votre adresse e-mail, le sujet et le contenu de votre message. Le nom de votre organisation est facultatif. Ces informations me permettent de comprendre votre demande et d’y répondre. Évitez d’inclure des mots de passe ou des informations sensibles.

Comment le message est acheminé

En envoyant le formulaire, vous transmettez ces informations au service externe FormSubmit (politique de confidentialité, PDF), qui les achemine vers ma messagerie professionnelle : messagerie@carlstephenjuniorpierrelouis.site. Une vérification anti-spam peut être affichée par ce prestataire.

Vous pouvez également utiliser directement votre logiciel de messagerie en cliquant sur mon adresse e-mail.

Navigation sur le portfolio

Le code de ce portfolio n’ajoute ni outil d’analyse d’audience ni cookie publicitaire. Les images et les styles sont chargés depuis le site. L’hébergeur et le service de formulaire peuvent traiter des données techniques selon leurs propres règles ; la vérification anti-spam se déroule sur le site du prestataire.

Une question sur vos données ?

Pour demander une information, une correction ou la suppression d’un message reçu, écrivez à messagerie@carlstephenjuniorpierrelouis.site.
